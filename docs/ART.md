# Art guide (for ComfyUI)

The mod builds with **placeholder sprites** generated by `tools/make_placeholders.py`.
Replace each file below with real art, keeping the **exact file name and pixel size**, then run
`python3 tools/check_art.py` to confirm the sizes before building.

| File | Size | What |
|---|---|---|
| `Content/Items/TomeConjureFireAtronach.png` | 32x32 | The spell tome (inventory icon) |
| `Content/Buffs/FireAtronachBuff.png` | 32x32 | Buff icon (small flame creature head or flame) |
| `Content/Projectiles/FireAtronachMinion.png` | **40x176** | Minion sprite sheet: **4 frames of 40x44 stacked vertically**, frame 0 on top |
| `icon.png` | 80x80 | Mod icon in the mod list |

Transparent background (real alpha) on all of them. The minion faces **right**; the game mirrors
it when it moves left. If you want a different frame size or count, change `FrameCount` and the
hitbox (`Width`/`Height`) in `Content/Projectiles/FireAtronachMinion.cs` and the line in
`tools/check_art.py`.

## Style target: vanilla Terraria

Terraria sprites are small, hand-pixeled, with a **dark 1px outline**, flat shading with 2 or 3 tones
per material, and a limited palette. They are not smooth and not anti-aliased. Compare against the
vanilla **Fire Imp**, **Meteor Head** and **Hellbat** (wiki.gg/terraria) for scale and palette.

- Hard pixel edges, no blur, no gradients, no semi-transparent edge pixels.
- Dark outline (near black with a warm tint, like `#2a120a`).
- Body palette: dark basalt rock `#3b2418`, `#5e3a24`, `#7d4d2e`; fire `#ff5a14`, `#ff9a1e`, `#ffd24a`, core `#fff1a8`.
- The fire in a Fire Atronach is the point: glowing cracks in a rock-and-ember humanoid body, a crown/mane of
  flames, hollow bright eyes, arms ending in flames. Floating (no legs, ember trail below).
- Do not copy the Skyrim model. Make it your own design that reads as a "fire atronach".

## Suggested ComfyUI workflow

1. Generate big (for example 512x512, or 1024x1024) with a pixel art LoRA / checkpoint.
   Positive prompt idea:
   `pixel art sprite, fire atronach, floating rocky humanoid made of dark basalt with glowing lava cracks, crown of flames, glowing eyes, flames for hands, side view facing right, 2D game sprite, Terraria style, dark outline, limited palette, plain solid background`
   Negative: `blurry, antialiased, gradient, 3d render, realistic, text, watermark, multiple characters, cropped`
2. Use a **solid flat background** (magenta `#ff00ff` works well), then remove it to transparency.
3. Downscale with **nearest neighbour** (never bicubic) to the target size. For the minion, generate or edit
   to about 40x44 per frame. Clean up the stray pixels by hand (Aseprite, Pixelorama, LibreSprite).
4. Make the 4 frames: easiest is to draw one clean frame, then shift/flicker the flame crown and bob the
   body 1 to 2 px up/down across frames (idle hover loop). Stack them vertically into the 40x176 sheet.
5. Save over the placeholder, run `python3 tools/check_art.py`.

A pixel-art LoRA for SDXL or Flux and the "pixelate with nearest + palette reduce" nodes
(for example the `ComfyUI-PixelArt` style nodes) fit this well. Any workflow that ends in a clean
indexed PNG at the right size is fine.
